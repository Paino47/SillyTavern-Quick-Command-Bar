# User 面具工坊

SillyTavern 第三方 UI 扩展。把 User Persona 拆成可复用的资料区块，再按需要组合成不同的面具方案。

## 设计目标

不是一次性填写表单，而是建立自己的 User 资料库。姓名、年龄、身高、体重、外貌、性格、身世、经历、习惯、偏好、身份关系等内容都可以单独保存；一个区块可以被多个面具重复使用。

## 功能

- **区块库**：自由新建、编辑、删除和分类资料区块；支持按名称、分类、内容与标签搜索。
- **标签**：每个资料区块可添加多个标签，便于跨分类检索和整理。
- **自定义分类管理**：可重命名或删除自定义分类；删除分类时，其下区块会转移到“补充设定”，不会被删除。
- **批量选择**：可全选当前筛选结果或手动勾选区块，一次性加入合成台；自动跳过已加入的重复区块。
- **常用字段模板**：一键生成姓名、年龄、身高体重、性格、身世经历等空白字段，按需填写。
- **合成台**：从区块库挑选素材，支持拖拽排序，也保留上下移动按钮；实时预览最终 User Persona 文本。
- **面具方案**：保存多套组合，例如现代日常、古风架空、校园身份、特殊剧情身份；可展开查看每套方案的实时文本预览。载入时会先提醒当前合成台将被替换，不会复制或破坏原始区块。
- **面具组合**：可同时选择多套已保存面具，将其中区块按方案顺序合并到合成台，并自动去重。
- **导入 / 导出**：备份完整区块库与面具方案为 JSON，也可导出当前合成文本。
- **写入当前 Persona**：将预览文本写入 SillyTavern 当前人设的描述框，并触发原生输入保存逻辑。只改描述，不改名称、头像和人设绑定。

## 数据保存

区块库、面具方案和当前合成顺序保存在 SillyTavern 的扩展设置中，并通过扩展设置保存机制持久化。建议定期导出 JSON 备份。

## 安装

当前版本作为独立扩展目录放在本仓库的 User-Persona-Forge 文件夹中。将整个文件夹复制到：

public/scripts/extensions/third-party/user-persona-forge/

然后在 SillyTavern 的扩展管理中启用并刷新页面。

> 本目录是独立扩展包；由于它目前位于另一个扩展仓库的子目录，不能直接把父仓库 URL 粘贴进 ST 的“安装扩展”功能。后续将其迁移到独立仓库后即可使用 Git URL 安装。

## 使用

1. 点击酒馆顶栏的“面具工坊”。
2. 在“区块库”中新建内容，或先用“常用字段”建立空白条目。
3. 点击区块上的“加入合成”，或勾选多个区块后使用“批量加入合成台”。标签可在编辑区块时填写，使用逗号分隔。
4. 在“已保存面具”中勾选多套方案，可将它们的区块合并到当前合成台；相同区块只会加入一次。
5. 在合成台调整顺序、检查预览；需要长期复用时保存为面具方案。
6. 选择“复制文本”后粘贴到 User Persona，或直接选择“写入当前人设”；扩展会调用酒馆 Persona 描述框的原生输入处理，不要求先展开 Persona 管理面板。

## 兼容性说明

使用 SillyTavern 的 getContext / extensionSettings 持久化接口；写入当前 Persona 时调用原生 Persona 描述框的 input 事件处理逻辑。若酒馆版本调整了 Persona 面板 DOM 结构，直接写入功能可能需要适配；复制文本功能不依赖该 DOM 结构。
